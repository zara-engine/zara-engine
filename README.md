🏆 **Призёр** научно-практической конференции **«Инженеры будущего»**
(направление IT-вертикаль) — проект **«МЭШ.Импульс»**, легковесный
Telegram-бот для быстрого доступа к учебным данным.

Мне 14, и мне нравится разбираться, как всё устроено «под капотом»:
от заголовков HTTP-запросов до архитектуры нейросетей.

## 🛠 Технологии

**Reverse engineering и работа с API**
- Анализ сетевого трафика (DevTools), восстановление структуры
  недокументированных API
- Работа с HTTP-заголовками, токенами, обход защит от автоматизации
- REST API, JSON, парсинг и фильтрация данных

**Язык и боты**
- Python
- aiogram (асинхронные Telegram-боты)
- Интеграция API популярных ИИ-моделей в ботов

**ИИ / Machine Learning**
- Изучаю архитектуру Transformer
- Подключение и использование API больших языковых моделей

**Инструменты**
- Git, GitHub

## 🚀 Чем могу быть полезен

- Разработка Telegram-ботов под конкретную задачу
- Интеграция ботов с внешними API (включая ИИ-модели)
- Сбор и анализ открытых данных (парсинг, мониторинг цен/ассортимента)
- Исследование и интеграция недокументированных API
- Python-скрипты для автоматизации

## 📌 О проектах

В закреплённых репозиториях — мои учебные и исследовательские работы.
Проект «МЭШ.Импульс» показал реальные результаты: переход от тяжёлого
графического интерфейса к текстовому сократил трафик примерно в 600 раз
и ускорил получение данных примерно в 20 раз.
