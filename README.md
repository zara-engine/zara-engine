🏆 **Призёр** научно-практической конференции **«Инженеры будущего»**
(IT-направление) — проект **«МЭШ.Импульс»**, легковесный
Telegram-бот для быстрого доступа к учебным данным.
 
Люблю разбираться, как всё устроено «под капотом»:
от заголовков HTTP-запросов до архитектуры нейросетей.
 
## 🛠 Технологии
 
**Reverse engineering и работа с API**
- Анализ сетевого трафика (DevTools), восстановление структуры
  недокументированных API
- Парсинг сайтов с антибот-защитой (Wildberries, Ozon и др.):
  токены, заголовки, client hints, TLS-отпечатки
- REST API, JSON, парсинг и фильтрация данных
**Язык и инструменты**
- Python: aiogram, Playwright, curl_cffi, httpx, openpyxl
- Интеграция API популярных ИИ-моделей в ботов
- Git, GitHub
**ИИ / Machine Learning**
- Изучаю архитектуру Transformer
- Подключение и использование API больших языковых моделей
## 🚀 Чем могу быть полезен
 
- **Мониторинг цен и наличия** на маркетплейсах (WB, Ozon и др.)
  с уведомлениями в Telegram и отчётами в Excel / Google Таблицах
- **Парсинг и сбор открытых данных**, в том числе с защищённых сайтов
- **Telegram-боты** под конкретную задачу, интеграция с внешними API и ИИ-моделями
- **Python-скрипты** для автоматизации рутины
- **Запуск на сервере и поддержка**: размещу проект, чтобы он работал 24/7,
  и поправлю, если сайт что-то поменяет
